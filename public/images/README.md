# Premium Hero Image

## Required Image: entry-hero-premium.jpg

To complete the premium entry page design, add a hero image with these specifications:

### Image Specifications
- **Filename:** `entry-hero-premium.jpg`
- **Location:** `/public/images/entry-hero-premium.jpg`
- **Recommended dimensions:** 1920x1080 or higher
- **Format:** JPG or JPEG

### Recommended Image Style
- Soft daylight photography
- Beauty products on a stone or marble counter
- Diffused, natural lighting
- Mild pastel color palette (soft pinks, creams, whites)
- Clean, minimal composition
- Professional product photography aesthetic

### How to Add the Image

1. Download a suitable image from Pexels or your own source
2. Rename it to `entry-hero-premium.jpg`
3. Place it in the `/public/images/` directory
4. The entry page will automatically use it as the hero background

### Alternative: Temporary Placeholder

If you want to test the layout before adding the final image, you can use any temporary image with the correct filename. The design includes overlays and blur effects that work with most beauty/cosmetic product photography.
